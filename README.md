# החלק לקלפי

משחק החלקה בסגנון טינדר: שייכו את 20 המועמדים הראשונים של ביחד (בנט), ישר! (איזנקוט), הדמוקרטים (גולן) וישראל ביתנו (ליברמן) לפתק הנכון.

- ימינה: ביחד (רק)
- שמאלה: ישר! (דרך)
- למעלה: הדמוקרטים (אמת)
- למטה: ישראל ביתנו (ל)

פותחים את `index.html` בדפדפן. בסוף מוצגת התוצאה לכל מפלגה, עם שיתוף ל־X ולפייסבוק ותמונת תוצאה.
